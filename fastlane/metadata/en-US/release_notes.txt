File and attachment capture is more reliable in this update. You can now send a file, photo, scan, sketch, or recording without adding text first, and Vox.md keeps it in the Markdown note where it belongs.

Improved
• File imports now open directly in Quick Capture.
• Attachment-only captures save correctly instead of being rejected as empty.
• Capture templates preserve custom filenames more consistently.
• Apple Watch recordings transfer, refresh, and export more reliably.
