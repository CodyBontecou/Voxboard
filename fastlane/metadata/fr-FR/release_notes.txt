Enregistrez des notes vocales depuis votre Apple Watch, puis laissez Vox.md les synchroniser vers votre iPhone à la reconnexion.

Nouveau dans cette mise à jour :
• Enregistrement Apple Watch — démarrez et arrêtez des notes vocales locales sur la Watch sans prendre votre iPhone.
• File d’attente Watch — les enregistrements restent sauvegardés sur l’Apple Watch et arrivent dans la file de votre iPhone quand les appareils se reconnectent.
• Statuts plus clairs — les états Prêt, Enregistrement, Synchronisation, En file et Envoyé ont été repensés pour mieux comprendre ce qui se passe.
