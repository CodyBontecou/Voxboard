Новое в этом обновлении:
• Тактильная обратная связь клавиатуры — нажатия теперь имеют тактильную обратную связь по умолчанию, с переключателем в Настройках для её отключения.
• Всплывающие акценты при долгом нажатии — удерживайте клавишу на языках с латинским шрифтом для доступа к вариантам с акцентами (à, é, ñ, ü, и т.д.).
• Локализованные сообщения состояния на панели инструментов клавиатуры для всех поддерживаемых языков.
• Исправление ошибки для записей внутри приложения, которые могли вызывать дублированные IPC ответы.
