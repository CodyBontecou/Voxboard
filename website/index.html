06 / FAQ

What people ask before installing a keyboard.

The short version: Voxboard is a free download, works inside iOS text fields, and is designed so private dictation does not require cloud transcription.

Do I need to enable Full Access?

No. Voxboard's keyboard extension does not request or require Apple's Full Access setting. The keyboard is designed to operate without network connectivity.

Does Voxboard upload my audio?

No. Microphone audio is processed locally by the on-device transcription engine, is not saved as raw audio, and is not sent to a server or third-party API.

Can I use it offline?

Core voice-to-text can run locally after setup with an installed model. The bundled Base model is included; downloading optional larger models, opening the App Store, and some setup analytics require a network connection.

Which apps does it work with?

Voxboard works anywhere iOS shows a standard text field: Safari, Messages, Notes, Mail, search boxes, chat apps, forms, and more. Use the globe key to switch keyboards.

How accurate is the transcription?

Accuracy depends on the selected model, language, background noise, accent, and microphone quality. Larger models can improve results but use more storage and processing power. Verify critical text before sending.

How much storage do models need?

The bundled Base model is about 142 MB. Optional models range from Tiny at about 75 MB to Large v3 Turbo at about 1.6 GB. You can choose the model size that fits your device.

What does Voxboard cost?

Voxboard is a free download from the App Store. This site does not list paid tiers; check the App Store listing for the current pricing shown by Apple.
