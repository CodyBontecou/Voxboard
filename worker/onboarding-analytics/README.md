# Voxboard Onboarding Analytics Worker

Cloudflare Worker + D1 ingestion endpoint for Voxboard onboarding analytics.

- Production URL: `https://voxboard-onboarding-analytics.costream.workers.dev`
- Ingest endpoint: `POST /v1/events`
- Health check: `GET /health`
- Storage: D1 table `onboarding_events` in D1 database `voxboard-onboarding-analytics` (`af59f484-87cd-4f0b-b4ab-c5225125c50d`)
- Query surface: Wrangler CLI
- UI: none

## Privacy contract

The worker stores only validated, coarse onboarding/activation fields:

- anonymous app-install UUID generated by Voxboard
- event name
- experiment/variant IDs
- app version/build/platform
- coarse onboarding step
- microphone permission status
- model engine and size bucket
- file-export format/mode only
- free-tier usage buckets
- paywall context
- product ID
- purchase/restore outcome
- coarse error category

It rejects unknown event names/properties and does **not** store audio, recordings,
transcript text, dictated text, keystrokes, file/folder paths, custom template
text, model file paths, user-entered names, email addresses, raw request IPs,
user agents, raw timestamps, or device names.

## Setup

```bash
cd worker/onboarding-analytics
npm install
npm run db:create
# copy database_id into wrangler.toml
npm run db:migrate:local
npm run db:migrate:remote
wrangler secret put INGEST_TOKEN # optional
npm run deploy
```

Configure the app with:

```text
ONBOARDING_ANALYTICS_ENDPOINT_URL=https://<worker-host>
ONBOARDING_ANALYTICS_INGEST_TOKEN=<same token as INGEST_TOKEN, if configured>
```

`Voxboard/Info.plist` currently sets `ONBOARDING_ANALYTICS_ENDPOINT_URL` to the production Worker URL. No `INGEST_TOKEN` secret is configured in production today, matching the Health.md analytics worker setup.

## Query examples

Recent events:

```bash
wrangler d1 execute voxboard-onboarding-analytics --remote --command \
"SELECT received_at,event_name,variant_id,platform,onboarding_step,paywall_context,purchase_outcome
 FROM onboarding_events
 ORDER BY received_at DESC
 LIMIT 20;"
```

Onboarding funnel:

```bash
wrangler d1 execute voxboard-onboarding-analytics --remote --command \
"SELECT
   variant_id,
   COUNT(DISTINCT CASE WHEN event_name='onboarding_started' THEN install_id END) AS starts,
   COUNT(DISTINCT CASE WHEN event_name='onboarding_microphone_permission_completed' AND permission_status='granted' THEN install_id END) AS mic_grants,
   COUNT(DISTINCT CASE WHEN event_name='onboarding_completed' THEN install_id END) AS completions,
   SUM(CASE WHEN event_name='onboarding_paywall_shown' THEN 1 ELSE 0 END) AS paywall_views,
   SUM(CASE WHEN event_name='onboarding_purchase_finished' AND purchase_outcome='succeeded' THEN 1 ELSE 0 END) AS purchases
 FROM onboarding_events
 GROUP BY variant_id
 ORDER BY variant_id;"
```
